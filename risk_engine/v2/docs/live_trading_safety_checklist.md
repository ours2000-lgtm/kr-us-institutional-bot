# live_trading_safety_checklist.md
# Live Trading Safety Constitution
# Version: 1.0 (FOUNDATION)
# Status: FINAL — ENFORCED

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
본 문서는 자동매매 시스템의 **운영 헌법(Operating Constitution)** 이다.

목적:
- 실계좌(live) 운용 시, 시스템이 절대 넘어서는 안 되는 안전 기준을 정의한다.
- 수익보다 **생존(survival)** 을 우선하는 불변 규칙을 명문화한다.
- 실험, 전략, 코드 변경은 본 헌법을 침범할 수 없다.

원칙:
- ✔ 절대 금지 (Hard Stop): 위반 시 즉시 신규 주문 중단
- ⚠ 경고 (Soft Stop): 축소/제한/사람 확인 필요
- ○ 허용 (Allowed): 정상 운영 범위

## A. PnL / 손실 가드 (Profit & Loss Guard)

✔ 일일 손실 한도 초과  
- 기본 행동: 모든 신규 주문 즉시 중단
- 사람 개입: 필수 (사람 승인 전 재시작 불가)

✔ 최대 누적 드로우다운 초과  
- 기본 행동: 시스템 강제 중지
- 사람 개입: 필수 (전략/시스템 재검토)

⚠ 연속 N 거래일 손실  
- 기본 행동: 신규 주문 제한 또는 포지션 축소
- 사람 개입: 권장

⚠ 연속 N 트레이드 손실  
- 기본 행동: 해당 전략 자동 감속
- 사람 개입: 선택

○ 소폭 손실 / 정상 변동  
- 기본 행동: 정상 운영


## B. 익스포저 / 포지션 가드 (Exposure & Position Guard)

✔ 계좌 총 익스포저 상한 초과  
- 기본 행동: 신규 주문 절대 금지

⚠ 단일 종목 / 시장 과도 편중  
- 기본 행동: 신규 진입 제한, 비중 축소

⚠ 전략별 포지션 상한 도달  
- 기본 행동: 해당 전략 신규 주문 제한

○ 정상 분산 상태  
- 기본 행동: 정상 운영


## C. 주문 / 마켓 마이크로 구조 가드 (Order & Microstructure Guard)

✔ 중복 주문 / 재전송 감지  
- 기본 행동: 즉시 차단

✔ 주문 빈도 폭주  
- 기본 행동: 즉시 신규 주문 중단

⚠ 슬리피지 / 스프레드 1차 초과  
- 기본 행동: 포지션 사이즈 축소 / 주문 빈도 제한

✔ 슬리피지 / 스프레드 2차 심각 초과  
- 기본 행동: 해당 심볼/전략 신규 주문 중단

○ 정상 체결 범위  
- 기본 행동: 정상 운영


## D. 환경 / 실험 가드 (Environment & Experiment Guard)

✔ 실험 플래그 ON 전략의 live 진입  
- 기본 행동: 절대 금지

✔ sim / paper / live 환경 혼용  
- 기본 행동: 절대 금지

⚠ 신규 전략 live 배포  
- 기본 행동: 제한적 허용 (사람 확인 필요)

○ 검증 완료된 운영 전략  
- 기본 행동: 정상 운영

○ paper 환경 전용 실험  
- 기본 행동: 허용 (live 절대 불가)


## E. 모니터링 / 알림 / 사람 개입 (Monitoring & Human Intervention)

✔ 손실 / DD 한도 초과 상태에서 재시작  
- 기본 행동: 절대 금지 (사람 승인 전 불가)

✔ 장중 가드 임의 해제  
- 기본 행동: 절대 금지

⚠ 반복 경고 이벤트 발생  
- 기본 행동: 알림 발송 + 감속

○ 정상 로그 / 알림  
- 기본 행동: 정상 운영

○ 비장중(야간) 수동 정지/청산  
- 기본 행동: 허용 (운영 권한 필요)


## F. 운영 / 장애 / 예외 처리 (Operations & Failure Handling)

✔ 브로커 / API 장애  
- 기본 행동: 신규 주문 즉시 중단

✔ 데이터 피드 끊김 / 이상  
- 기본 행동: 해당 전략/심볼 중단

⚠ 일시적 네트워크 문제  
- 기본 행동: 재시도 + 보수적 운영

○ 정상 시스템 상태  
- 기본 행동: 정상 운영


## G. 성능 / 지연 가드 (Performance & Latency Guard)

✔ 메인 루프 지연 연속 발생  
- 기본 행동: 신규 주문 중단

⚠ API 응답 지연  
- 기본 행동: 재시도 / 호출 빈도 감소

⚠ 성능 경고 반복 발생  
- 기본 행동: 전략 정지 가능

○ 정상 지연 범위  
- 기본 행동: 정상 운영


## H. 데이터 / 모델 무결성 가드 (Data & Model Integrity Guard)

✔ data_quality != ok  
- 기본 행동: live 신규 주문 절대 금지

✔ 가격/체결량 이상치 감지  
- 기본 행동: 자동 중단

✔ 미검증 모델 / 파라미터  
- 기본 행동: live 사용 절대 금지

⚠ 백테스트/페이퍼 기간 부족  
- 기본 행동: 추가 검증 필요

○ 검증 완료 상태  
- 기본 행동: 정상 운영
